# Sales Performance Dashboard (Power BI)

This project analyzes sales, revenue, discounts and profit using Power BI connected to a MySQL database.

## Key Features
- Revenue by Product and Region
- Profit After Discount
- Discount Analysis
- Interactive slicers
- Yearly & Quarterly trend analysis

## 🛠 Tools Used
- Power BI
- MySQL
- SQL
- DAX

## Dataset
Sales data includes:
- Order date
- Product
- Category
- Region
- Sales ($)
- Cost
- Discount %

## Business Insights
This dashboard helps identify:
- Best performing products
- Most profitable regions
- Discount impact on profit
- Revenue trends over time
